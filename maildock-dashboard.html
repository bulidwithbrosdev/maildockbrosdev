🚀 Deploy Maildock

Build and deploy to Cloudflare Workers in one command.

Pre-flight Checklist
Node.js ≥ 22 installed
Run node --version in terminal
Wrangler authenticated
Run npx wrangler whoami — must show your Cloudflare account
Dependencies installed
Run npm install inside the project root
D1 database migrated (first deploy)
The Worker auto-applies migrations on startup — no manual step needed
Auto
Deploy Commands
Full Deploy (Build + Deploy)
Builds both the Worker and the web app, then deploys to Cloudflare. Use this for production releases.
cd d:\Maildock\Maildock && npm run deploy
  1. Runs vite build → compiles TypeScript, bundles React into dist/client/ and the Cloudflare Worker into dist/maildock/.
  2. Runs npx wrangler deploy → uploads the Worker script and assets to Cloudflare's edge network.
  3. Wrangler auto-creates the D1 database if it doesn't exist on your account.
  4. The Worker applies its own SQL migrations on the first request.
Login to Wrangler (run once)
Authenticates Wrangler with your Cloudflare account via browser OAuth. Only needed once per machine.
npx wrangler login
npx wrangler whoami
Deploy Workflow
1
Clone / open the repo
Ensure you are inside d:\Maildock\Maildock
2
Run npm install
Install all Node.js dependencies
3
Run npx wrangler login
Authenticate with Cloudflare — once per machine
4
Run npm run deploy
Builds and deploys the Worker. Wrangler creates D1 automatically.
5
Open the Worker URL and complete Setup
First visit shows the Setup wizard: paste your Cloudflare API token, create the admin account.

Production Secrets (wrangler secret put)

              
In production, set secrets via the Cloudflare dashboard or these commands. The ENCRYPTION_KEY is auto-generated by the Setup wizard.

            

          

          

            

              npx wrangler secret put ENCRYPTION_KEY --config wrangler.jsonc
              
            

            

              npx wrangler secret put CF_API_TOKEN --config wrangler.jsonc
              
            

            

              💡 Setup wizard sets secrets automatically. When you first open the app, the Setup page asks for your Cloudflare API token and stores it as a Worker secret via the Cloudflare API — no terminal needed.

🛠️ Build & Dev Server

        
Build the project locally or start the development server.

      


      

        

          

            

              
Build (Production)

              
Compiles TypeScript, bundles React, and produces Worker output in dist/.

            

          

          

            

              cd d:\Maildock\Maildock && npm run build
              
            

          

        


        

          

            

              
Type Check

              
Validates all TypeScript types across Worker, Web, and Node scripts. No compilation output.

            

          

          

            

              cd d:\Maildock\Maildock && npm run typecheck

Terminal 2 — Vite Dev Server

            

              cd d:\Maildock\Maildock && npm run dev
              
            

            
App will be available at http://localhost:5173

🗄️ Database Migrations

        
Cloudflare D1 (SQLite). The Worker auto-runs migrations on startup — manual runs are for local dev or troubleshooting.

      


      

        

          

            

              
Apply Migrations — Local (dev)

              
Applies all pending SQL migrations to your local D1 dev database.

            

          

          

            

              cd d:\Maildock\Maildock && npm run db:migrate:local
              
            

            

              
              

                Runs wrangler d1 migrations apply DB --local. Applies all *.sql files in src/worker/db/migrations/ to the local Wrangler D1 SQLite database (stored in .wrangler/state/). Safe to run multiple times — already-applied migrations are skipped.
              

            

          

        


        

          

            

              
Apply Migrations — Remote (production)

              
Applies migrations to your live Cloudflare D1 database. Only needed if the Worker auto-migration fails.

            

          

          

            
⚠️ This runs against your production database. Make sure you have a backup or know what the migration does.

            

              cd d:\Maildock\Maildock && npm run db:migrate:remote
              
            

          

        


        

          

            

              
List Applied Migrations

              
Check which migrations have been applied to the local or remote D1 database.

            

          

          

            
Local

            

              npx wrangler d1 migrations list DB --local --config wrangler.jsonc
              
            

            
Remote

            

              npx wrangler d1 migrations list DB --remote --config wrangler.jsonc
              
            

          

        

      


      

        
Migration Files

        

          

            src/worker/db/migrations/

            ├── 0001_init.sql

            ├── 0002_...sql

            ├── ... (through 0010)

            └── 0011_subdomains.sql  ← subdomain provisioning
